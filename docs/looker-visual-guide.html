Prepare the sheet: roster and feed tabs

Sheets5 min

Looker Studio needs one tab with one row per candidate. That includes people who haven't submitted yet, which the Algorithm Engine can't show. Candidate_Roster lists everyone you've invited, and Dashboard_Feed combines it with the form results.

  1. 1
    Add a tab named Candidate_Roster. Click A1 and paste the sample below. It contains your three test candidates plus one person who hasn't submitted (Alex Rivera).
  2. 2
    Select G2:G ▸ Insert ▸ Dropdown (Einfügen ▸ Drop-down) with the options Pending and Complete. This is the hiring manager's review tick.
  3. 3
    Add a tab named Dashboard_Feed. Click A1 and paste the formula below. Set the two switches at the top of the page first.
  4. 4
    Check the result: 4 rows, one per person, with an Evaluation Status for each.
Candidate_Roster sample, paste at A1
Candidate Name	Email	Discipline	Target Role	Hiring Manager	Invited On	Manager Review
Jessica		Software	Senior PM	You	2026-09-15	Pending
Trial candidate 2		System	Senior PM	You	2026-09-15	Complete
Test Candidate		System Validation	Senior PM	You	2026-09-10	Pending
Alex Rivera		Quality	Quality Lead	You	2026-09-18	Pending
Dashboard_Feed paste at A1US · Email B
=ARRAYFORMULA(LET(
  engMail, 2, engName, 3,
  roster, IFERROR(FILTER(Candidate_Roster!A2:G, Candidate_Roster!A2:A <> "")),
  eng,    IFERROR(SORT(FILTER('Algorithm Engine'!A2:AT, 'Algorithm Engine'!A2:A <> ""), 1, FALSE)),
  rKey,   IFERROR(LOWER(TRIM(IF(CHOOSECOLS(roster, 2) <> "", CHOOSECOLS(roster, 2), CHOOSECOLS(roster, 1)))), ""),
  eKey,   IFERROR(LOWER(TRIM(IF(CHOOSECOLS(eng, engMail) <> "", CHOOSECOLS(eng, engMail), CHOOSECOLS(eng, engName)))), ""),
  keys,   SORT(UNIQUE(FILTER(VSTACK(rKey, eKey), VSTACK(rKey, eKey) <> ""))),
  R, LAMBDA(c, ARRAYFORMULA(IFERROR(VLOOKUP(keys, HSTACK(rKey, roster), c + 1, FALSE), ""))),
  E, LAMBDA(c, ARRAYFORMULA(IFERROR(VLOOKUP(keys, HSTACK(eKey, eng),    c + 1, FALSE), ""))),
  submitted, E(1),
  score,     E(42),
  status, IF(submitted = "", "Pending Self-Assessment",
          IF(R(7) = "Complete", "Evaluated", "Pending Manager Review")),
  VSTACK(
    {"Email","Candidate Name","Discipline","Role","Hiring Manager","Invited On","Evaluation Status",
     "Submitted On","Match Score","Critical Gaps","Readiness","Meets Threshold"},
    HSTACK(
      IF(R(2) <> "", R(2), E(engMail)),
      IF(R(1) <> "", R(1), E(engName)),
      IF(R(3) <> "", R(3), E(4)),
      IF(E(5) <> "", E(5), R(4)),
      R(5),
      IF(R(6) = "", "", TO_DATE(R(6))),
      status,
      IF(submitted = "", "", TO_DATE(submitted)),
      IF(ISNUMBER(score), score, ""),
      E(43), E(45), IF(E(46) = "", "No", E(46))))
))
How candidates are matchedBy email if both sides have one, otherwise by name (capital letters don't matter). Your form isn't collecting emails yet, so leave column B of the roster empty for now. Otherwise a roster email and a nameless form row count as two people. Once you turn on email collection, fill in the roster emails.

Connect Looker Studio to Dashboard_Feed

Looker Studio3 min
  1. 1
    Open lookerstudio.google.com with the same Google account. Click Blank report (Leerer Bericht). The first time, accept the terms and pick your country.
  2. 2
    A panel Add data to report (Daten zum Bericht hinzufügen) opens. Choose Google Sheets (Google Tabellen) and click Authorize if asked.
  3. 3
    Pick Competencie Baseline, then the worksheet Dashboard_Feed.
  4. 4
    Leave Use first row as headers ticked. Click Add (Hinzufügen), then Add to report in the confirmation.

Looker drops a table onto the page automatically. Delete it (select it, then press Del) so you start with an empty page.

Fix the field types

Looker Studio3 min
  1. 1
    Menu Resource ▸ Manage added data sources (Ressource ▸ Hinzugefügte Datenquellen verwalten), then Edit next to Dashboard_Feed.
  2. 2
    In the Type column (Typ), change:
    • Match Score → Numeric ▸ Percent
    • Invited On → Date & Time ▸ Date
    • Submitted On → Date & Time ▸ Date
    • Critical Gaps → Number
  3. 3
    At the top, set Data freshness (Datenaktualität) to 15 minutes, and Data credentials (Anmeldedaten) to Owner's (Inhaber), so viewers don't need access to the sheet.
  4. 4
    Stay on this screen for Step 4.
4

Add four calculated fields

Looker Studio4 min
  1. 1
    On the same screen, click Add a field ▸ Add calculated field (Feld hinzufügen ▸ Berechnetes Feld).
  2. 2
    Type the Field name exactly as shown below, then paste its Formula. A green tick under the formula means it's valid.
  3. 3
    Click Save, then repeat for the other three. When all four are done, click Done and close the panel.
Is Submitted
CASE WHEN Evaluation Status IN ("Evaluated", "Pending Manager Review") THEN 1 ELSE 0 END
Is Fully Evaluated
CASE WHEN Evaluation Status = "Evaluated" THEN 1 ELSE 0 END
Is Qualified
CASE WHEN Meets Threshold = "Yes" THEN 1 ELSE 0 END
Days Waiting
DATE_DIFF(TODAY(), Invited On)

Looker Studio formulas always use commas, even in a European-locale account, so the Formula style switch doesn't change these.

Scorecards: how many candidates are evaluated

Looker Studio3 min
  1. 1
    Toolbar Add a chart ▸ Scorecard (Diagramm hinzufügen ▸ Kurzübersicht). Click the canvas to place it.
  2. 2
    In the Setup panel on the right, under Metric (Messwert), click the field and choose Is Submitted. Its aggregation shows SUM, which is what you want.
  3. 3
    Click the small pencil on the metric chip and rename it Self-assessments done.
  4. 4
    Copy the scorecard twice (Ctrl+C, Ctrl+V). Set one to Is Fully Evaluated ("Fully evaluated") and the other to Record Count (Datensatzanzahl) ("Candidates in pipeline").

Bar chart: candidates meeting the threshold, by role

Looker Studio3 min

7

Table: who is still missing an evaluation

Looker Studio4 min
  1. 1
    Add a chart ▸ Table (Tabelle).
  2. 2
    Dimensions: Candidate Name, Role, Discipline, Hiring Manager, Evaluation Status, Invited On. Use Add dimension for each.
  3. 3
    Metric: Days Waiting. Click its aggregation badge and choose MAX. Remove Record Count if Looker added it.
  4. 4
    Scroll the Setup panel to Filter ▸ Add a filter (Filter hinzufügen) ▸ Create a filter. Set it up as in the second illustration, name it Missing evaluation, and click Save.
  5. 5
    Sort: Days Waiting, Descending. Optionally, in Style ▸ Conditional formatting add a red background when Days Waiting > 7.
8

Discipline donut and the two filters

Looker Studio4 min
  1. 1
    Add a chart ▸ Pie and pick the donut icon (Ringdiagramm). Dimension: Discipline. Metric: Record Count.
  2. 2
    Add a control ▸ Drop-down list (Steuerelement hinzufügen ▸ Drop-down-Liste). Place it at the top of the page.
  3. 3
    Control field: Role. Metric: Record Count, so each option shows how many candidates it has. In Style, turn on Multiple selections.
  4. 4
    Copy the control and change its field to Discipline.
  5. 5
    Click View (Ansehen) at the top right and try the filters. Every chart on the page updates. On a multi-page report, right-click a control ▸ Make report-level (Auf Berichtsebene) so it filters every page.

If something's off

What you seeLikely causeFix
Dashboard_Feed shows a formula parse errorWrong formula style for your localeSwitch Formula style to European and copy again
Dashboard_Feed shows each person twiceThe roster has an email but the form row doesn't (or the name is spelled differently)Leave roster emails empty until the form collects them, and match the names exactly
Names appear in the Email columnThe wrong column-order switchPick Name in B, Email in C and copy the formula again
Everyone is Pending Self-AssessmentDashboard_Feed can't read the engineCheck that Algorithm Engine row 2 onwards has data, then the column-order switch
Days Waiting is empty or nullInvited On isn't a date in the sheet, or its field type isn't DateType dates as 2026-09-15 in the roster, and set the type to Date (Step 3)
Match Score shows 67 instead of 67%Its type is still NumberSet Match Score to Percent (Step 3)
A new field or column doesn't appear in LookerLooker cached the old column listResource ▸ Manage added data sources ▸ Edit ▸ Refresh fields
The filter hides everythingA typo in the filter valuesEdit the filter and pick the values from the list instead of typing them
